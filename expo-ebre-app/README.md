# Expo Ebre Tortosa 2026 App

Aplicación web divertida y llamativa para la Expo Ebre de Tortosa 2026. Incluye un mini juego donde los visitantes pueden poner a prueba sus reflejos haciendo clic en un objetivo que se mueve.

## Uso

1. Instala las dependencias si las hubiera: (no hay dependencias por ahora).
2. Ejecuta el servidor:
   ```bash
   npm start
   ```
3. Abre tu navegador en `http://localhost:3000` y juega.

## Mini Juego

- Pulsa **Comenzar juego** para iniciar.
- Haz clic en el círculo naranja tantas veces como puedas en 10 segundos.
- Tu puntuación final se mostrará en pantalla.

¡Disfruta la Expo Ebre Tortosa 2026!
